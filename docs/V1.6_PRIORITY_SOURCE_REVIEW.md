## Dedicated Damai adapter

`crawler/sources/event_platform/damai.py` replaces the generic page-audit placeholder while preserving source_id=platform-damai-suzhou and the existing CLI alias. It accepts only the public search root and canonical HTTPS detail.damai.cn/item.htm?id=<numeric ID> URLs. Explicit detail seeds are URL-discovery candidates, not verified event records. They are checked against their own host's robots; blocked search is never requested or emulated.

The adapter has no search/private API, mobile-app, browser, purchase, login, CAPTCHA-solving or token path. Robots checks happen first, with an explicit can_fetch stop before any page request. Only absent rules via HTTP 404/410, an empty robots file, or usable parsed rules permit a page check. HTML, HTTP errors and robots redirects fail closed. Crawl delay, request spacing, response bounds and audit logging retain the existing client behavior. Login/private-route redirects are rejected before the target is requested. An access-wall page is retained raw and stops further details.

`crawler/extractor/damai.py` accepts exactly one complete public Event JSON-LD record and extracts:

| Required data | Source and safeguards |
| --- | --- |
| Event name | JSON-LD.name; nonempty |
| Category | Explicit Event subtype mapped to existing category vocabulary; Needs Review |
| Date | Valid explicit startDate; sale dates, title years and ambiguous ranges are excluded |
| Venue | Explicit JSON-LD.location.name |
| City | Explicit addressLocality matching Suzhou; title alone is not city evidence |
| Source URL | Actual permitted response URL; a provided canonical item URL must match |

Explicit aware timestamps are converted to Suzhou UTC+08 calendar dates; raw timestamp snippets remain intact. Missing endDate/organiser/address stay null. Wrong-city, incomplete, cancelled/postponed, ambiguous or access-wall records are rejected. Untyped inline JS and private API state are not guessed or executed.

The new optional city value uses the existing normalized JSON and evidence tables. Event payloads expose city, and field evidence retains value, source URL/name, raw_item_id, snippet, method, heuristic confidence and verification status. City evidence is opt-in for observations that provide a city claim. Legacy events retain their existing ten-field evidence behavior when no city claim exists. No source or field automatically becomes Verified. Confidence remains an uncalibrated extraction score.

**This parser is validated with synthetic fixtures, not with a live Damai event body. Current Damai markup could not be verified because the permission gate stopped collection. Public HTML variants without supported Event JSON-LD remain unsupported; there is no API fallback.**

## Run

Use the existing backend/.venv interpreter from the repository root:

```bash
python -m pytest crawler/tests backend/tests -q
python -m crawler.run --source damai --max-items 2 --db /absolute/path/to/isolated.sqlite3 --coverage-report docs/damai-report.json
python -m crawler.run --source huodongjia --db /absolute/path/to/isolated.sqlite3 --coverage-report docs/huodongjia-report.json
python -m crawler.run --source expo --db /absolute/path/to/isolated.sqlite3 --coverage-report docs/expo-report.json
python -m crawler.inspect --db /absolute/path/to/isolated.sqlite3
```

Run these source checks sequentially when they share a database/registry. Last-observed statuses are snapshots, not continuing access guarantees. Failed refreshes retain existing event observations. Damai seeds can be changed only to approved canonical public detail URLs and still require a successful robots/access check.
