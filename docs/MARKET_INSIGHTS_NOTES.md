# 商圈洞察：口径、验收与已知限制（v20）

> 面向周四企业交流的「会被问倒」清单。所有数字来自生产环境实测（2026-10-26）。

## 一、这个页面的口径（必须先说清）

1. 商圈**没有官方边界**。我们只有「中心点 + 半径」，所以一律称 **「中心点近邻分析范围」**，不称「商圈内活动」。
2. 中心点来源分两类：**官方商圈 20 个**（高德 POI 反查，记录行政区一致性）+ **候选商业集聚点 33 个**（POI 聚类，未经官方确认，页面标「候选」）。
3. 落在多个中心半径内的活动**保留歧义**（当前 4 个），不强行归属。
4. **未匹配 ≠ 该商圈没有活动**（当前 185 个活动未匹配，占 416 的 44%）。
5. 酒店类数字统一称 **「已收录住宿设施」**：来自高德 POI，坐标系已检查，但**未经人工实地核验**存在性与营业状态。

## 三、五条「一定会被问」的已知限制（按概率排序）

1. **苏州这么大，为什么只有 488 家住宿设施？**
   → 这是五个采集区域（苏州/太仓/昆山/常熟/张家港）的高德住宿 POI 样本；高德搜索接口本身不返回全量，分页有上限。**不是普查，也不代表全部在营酒店。**
2. **这 53 个商圈是真实划定的吗？**
   → 不是。20 个既有中心 + 33 个候选集聚点；800 米是**分析半径**，不是真实商圈边界。附近酒店和活动不等于正式商圈成员。
3. **为什么某个商圈活动特别多？**
   → 一个候选中心集中了 147 个近邻活动，约占 227 的 **65%**，主要因苏州国际博览中心一带活动密集。**不能据此判断商业更繁荣**，页面「分析口径」里有集中度提示。
4. **酒店坐标、星级、经营状态可靠吗？**
   → 坐标来自高德 POI、通过坐标系检查，但**不等于人工实地核验**；星级只在 POI 类型串明确标注时才有（多数为空），营业状态、房价、房量均未确认。
5. **能算出商圈消费或酒店能多赚多少吗？**
   → **不能，也不做**。没有消费交易、入住率、ADR、客流基线；方法学梳理见 `docs/MARKET_CONSUMPTION_RESEARCH.md`（结论：金额类指标需真实交易数据 + 反事实基线）。
