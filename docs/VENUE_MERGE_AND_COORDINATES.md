## 三、过程中发现的三个缺陷

### 缺陷 1：检测器会提议错误的合并

跑检测器时它给出 10 组候选，其中 4 组是错的：

```
太仓市       →  太仓市博物馆        ← 城市名"包含"在博物馆名里
太仓市       →  太仓市图书馆
展厅         →  苏州市文联文艺家展厅   ← 通用词被配给 3 个不同场馆
展厅         →  定慧寺巷口凤凰街旅游咨询中心3楼展厅
展厅         →  常熟市文化艺术中心展厅
```

**`太仓市` 这行的成因**：官方文章提取把标题的「单位：」前缀当作场馆名，而全市范围活动的标题是

```
名称: 太仓市:捡个秋天·太仓漫游季
```

于是「太仓市」成了一个场馆行。**这是分类错误,不是重复** —— 把它并入博物馆会让两个不相关的地点变成一个。

**修复**：区域名不参与合并；通用词（展厅、剧院）永远不作别名；**一个别名只配一个主名**（原来是每个包含它的行都配一次）。

### 缺陷 2：合并会丢坐标

`merge()` 迁移事件、删除别名行，但**不转移坐标**。而检测器按"活动数多"选主名。

实测数据的组合：

```
苏州狮山大剧院   1 条活动   坐标=有   ← 唯一的高德记录
狮山大剧院      6 条活动   坐标=无   ← 会被选为主名
```

**合并后坐标消失,而这个场馆还剩 6 条活动。** 坐标是唯一无法通过重读源页面恢复的字段 —— 名称可以重新抓,坐标不行。

**修复**：选主名时坐标优先于活动数；`merge()` 只在主名缺该字段时从被合并行复制坐标和地址，**绝不覆盖已有值**。

### 缺陷 3：合并写的别名会让下一次采集失败

采集管线在把事件指向别名主场馆时，会先查 `canonical_venue_rows()`：

```python
if canonical is None:
    raise ValueError("Venue alias points at a canonical venue that is not declared: " + ...)
```

手工写的 3 条别名带 `canonical_row`，**而 `write_alias()` 不写这个字段** —— 所以通过维护接口做的每次合并，都会留下一个下次采集必然抛异常的别名。

**修复**：`merge()` 写入最终的 canonical_row（坐标已转移之后的版本）。测试锁住了这一点。

**这三个缺陷都不是本次报告的问题，是修它的过程中暴露出来的。** 第 3 个如果没发现，明天 08:00 的定时采集会失败。

## 四、坐标补充

用高德 Web 服务（`scripts/enrich_venue_coordinates.py`）查询：

| 结果 | 数量 |
| --- | ---: |
| 名称精确匹配 → 写为 **Verified** | **25** |

| 查询失败 | 0 |

**只有名称完全匹配才写入。** 部分匹配不写,因为其中确实有错的:

```
李公堤文化创意街区  →  匹配到「李公堤文化创意街区停车场」    ← 停车场不是场馆
苏州之眼          →  匹配到「苏州之眼摩天轮」             ← 可能对，但名称不同
白马涧龙池景区      →  匹配到「白马涧龙池景区-聆泉桥」       ← 桥不是景区
```

也有看起来正确的（`光裕书厅` → `光裕书厅(观前街店)`、`苏州博物馆` → `苏州博物馆(本馆)`），但脚本的保守策略是对的：**不确定就不写**，这符合项目原则。

### 坐标工具暴露的一个问题

它给 `太仓市` 提议了 **VERIFIED** 坐标 —— 高德确实返回一个叫「太仓市」的 POI，那是**城市中心点**。

**给"城市"赋予城市中心坐标,会让全市活动在地图上聚成一个点**,扭曲所有基于距离的判断。

**修复**：采集管线现在遇到区域名不创建场馆行（保留活动自己的 地点 声明和 district），并把已有的 `太仓市` 行移除（事件改为无场馆，记录在 `venue_edits`）。

写这个规则时我的第一版**过宽**：它把 `周庄古镇`、`黎里古镇`、`震泽古镇`、`天平山景区`、`金鸡湖景区` 都判成了区域名 —— 而这些在库里**已经有验证坐标**，误判会丢掉可用的地理数据。新测试抓到了这个错误。收紧后的规则：

- 市/省/区/县 必须**独占整名**（保住 `苏州市体育中心`、`苏州工业园区文化馆`）
- 镇/乡/街道 必须**结尾**且前一字不是地名标记（保住 `周庄古镇`，仍抓住 `周庄镇`）
- `景区/古镇/古城/公园` 结尾一律不算区域名

**这条规则是测试写出来之后才对的,不是我先想对的。**
