### 0.1 如果 ECS 是按量付费

三条路,任选:
1. **转包年包月**(推荐):控制台把实例转为包年包月,至少买 3 个月,然后申请备案服务号;
2. **再买一台最低配包年包月 ECS**(3 个月,几十元/月),用它的备案服务号提交;备案接入商同为阿里云,
   通过后域名指向现有 ECS 一般可行(同接入商);不确定就先问阿里云备案客服;
3. **换轻量应用服务器**:轻量也支持备案服务号(需符合条件的套餐),但迁移麻烦,不推荐现在做。

> 每台 ECS 最多 5 个备案服务号;一个服务号对应一个网站备案。

## 4. 提交步骤(阿里云备案系统)

1. 打开 `https://beian.aliyun.com` → 登录阿里云账号(和域名/ECS 同一账号)→ 开始备案;
2. 主体信息:按 §1 选个人/企业,填身份/证照信息;
3. 网站信息:填域名 `entgroup14.com` + 选择的**备案服务号**,填网站名称/服务内容;
4. 上传资料 + 阿里云 APP 人脸核验/拍照;
5. 提交 → **阿里云初审**(1–2 个工作日,会电话核实);
6. 初审通过 → 收到工信部**短信核验**链接,24 小时内完成核验;
7. **管局审核**(上海通管局,约 5–20 个工作日;以系统显示为准);
8. 通过后收到备案号:格式 **`沪ICP备XXXXXXXX号-1`**(上海)。

**审核期间注意**:
- 首次备案要求**网站不可访问**(现在域名正好被阿里云拦截,别试图绕过);
- 备案服务号、主体证件、域名持有者三者信息要一致(个人备案:域名持有者=主体;企业备案:域名持有者可为企业);
- 手机号保持畅通,别漏接阿里云初审电话。

## 6. 常见驳回原因与规避

| 驳回原因 | 规避 |
|---|---|
| 域名未完成实名认证 / 域名持有者与主体不一致 | 先做域名实名;个人备案时域名持有者=本人 |
| 备案服务号无效(按量付费/时长不足) | 按 §0.1 处理 |
| 网站名称含"情报/平台/公司/酒店/预订"等词 | 用 §3 的名称 |
| 网站描述写了经营/交易/票务/新闻 | 用 §3 的文案,如实但克制 |
| 手机号归属地/省份与主体不符 | 用实名手机号;异地居住按管局要求补居住证 |
| 照片/人脸核验不合格 | 阿里云 APP 里重拍,光线充足、四角完整 |
| 初审电话未接 | 提交后 3 天内保持电话畅通 |
