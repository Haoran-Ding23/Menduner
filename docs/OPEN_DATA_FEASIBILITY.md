# 苏州市公共数据开放平台:可用性核实(2026-10-16)

**结论一句话**:目录**公开可查**(无需登录,6023 条已发布资源);**数据取用需要登录**——平台服务端对匿名下载直接返回 `{"code":1003,"msg":"请先登录系统!"}`,无条件开放的资源也一样;有条件开放的资源还要走申请审批。我们想要的那几类"日粒度经营数据"里,**只有高新区有两条酒店月度/节假日营业信息**,而"商圈日客流、地铁站进出站量、各商圈每日营业额"**在目录里没有查到**。

> 本次核实只读:目录查询 + 少量资源详情 + 一次匿名下载探测。**没有注册账号、没有登录、没有申请、没有下载任何数据集。**

## 一、平台技术面(逐条实测)

| 项 | 实测结果 |
|---|---|
| 域名 | `https://data.suzhou.gov.cn` — 200,Vue SPA(需 JS 渲染,但数据接口是独立的) |
| `robots.txt` | **404**(无规则)。按本项目 `PublicClient` 的既有口径 = 无可用规则、未禁止 |
| 目录接口 | `POST https://data.suzhou.gov.cn/dii/catalog/cms/open/getResourcePage?current=1&size=100`,body `{"resourceName":"","isPublished":true,"resourceType":3}` → **200 JSON,无需登录** |
| 资源详情 | `POST …/dii/catalog/cms/open/getResourceInfo?id=<id>` → **200 JSON,无需登录** |
| 分类统计 | `POST …/dii/catalog/cms/open/getTypeCountList` → **200 JSON**(`openType`/`mountType` 计数) |
| 部门/标签树 | `POST …/dii/catalog/labelGroup/findFirstLevel` → `{"code":1003,"msg":"请先登录系统!"}` |
| 申请相关 | `POST …/dii/catalog/resource/open/apply/list`、`…/apply/myApplyList` → **都要登录** |
| 文件下载 | `GET …/dii/cms-web/file/catalogFileDownload?fileCode=…` → **200 `{"code":1003,"msg":"请先登录系统!"}`** |
| WAF | 有(CWAP-waf;缺会话 cookie 时可能返回 307/HTML 挑战,拿到 `wzws_cid` 后正常) |

**前端自己的判断逻辑**(从平台自己的打包代码里读出,`chunk-1a5496eb`):

```js
// 下载按钮只在“无条件开放”或“申请已通过”时显示
"1" === baseInfo.openAttribute || (baseInfo.openApply && baseInfo.openAuditPass)
// 但真正发起下载时仍然要求登录
downloadResourceFile(e){ if (this.isLogin) { url: "/file/catalogFileDownload" } … }
downloadSelection(){ if (this.isLogin) {…} else confirm("请先登录系统。") }
```

即:**无需审批 ≠ 无需账号**。

## 四、申请路径与建议清单

**制度通道是存在的**:平台自己的政策页原文写着"**及时审核开放数据申请**;……做好开放前咨询服务、开放中技术服务与开放后跟踪服务(责任单位:市数据局)"。接口层面也印证:`resource/open/apply/list`(可申请列表)与 `resource/open/apply/myApplyList`(我的申请)都存在,但**都要求登录**。

因此流程是:**注册并登录(企业/单位主体更可能通过)→ 在资源详情页对"有条件开放"的资源提交申请 → 提供方审批(`openApply`+`openAuditPass`)后下载**;无条件开放的资源不需要审批,但**下载同样要账号**。

**建议申请清单**(按对我们的价值排序):

| 优先级 | 资源 | 部门 | 为什么要 | 备注 |
|---|---|---|---|---|
| 1 | 高新区旅游住宿酒店营业信息(月度) | 高新区 | 唯一含**平均房价+平均出租率+营业收入**的目录项,是访谈里酒店最想要的口径 | 有条件开放,条件:提供方同意 |
| 1 | 高新区旅游住宿酒店节假日营业信息 | 高新区 | **按天**填报,直接对应"活动期日粒度"需求 | 有条件开放 |
| 2 | 高新区旅游景区营业收入信息(月度) | 高新区 | 游客量+景区收入,可作需求侧参照 | 有条件开放 |
| 2 | 姑苏区A级景区数量及客流量统计数据 | 姑苏区教体文旅委 | 无条件开放;已有联系人 薛岚 13812656106 | 先走登录下载 |
| 3 | 苏州市文旅消费聚集区情况 | 市文广旅局 | 官方认定的文旅消费聚集区名单,可用于商圈/场馆口径 | 无条件开放 |

## 五、能直接接进 Menduner 的部分

1. **目录监控(可选)**:目录接口公开且无需登录,可以在不取数据的前提下定期查"有没有新增/转为无条件开放的相关资源",作为人工申请的前置筛选。**注意**:本项目爬虫的原则是不登录、不取受限数据,所以**采集器只查目录,不碰数据下载**。

## 六、未核实 / 不能推出的结论

- **没有下载过任何数据集**,所以"某资源是否真的能下、内容质量、时效、字段是否与简介一致"**全部未核实**。
- 目录里的 `isDown=1` 只表示平台标记"有可下载文件",不等于我们有权或能取到。
- **不能**说"平台开放了苏州各商圈每日营业额"、"平台有地铁站进出站量"——全量 6023 条的名单与简介里都没有;你说过没核实到,这次核实结果与之一致。
- **不能**用目录里的"主题/部门入口"推断数据可得性;本报告每一条结论都标了来源(资源名+开放属性+简介原文)。
- 平台标注的 `updateFrequency` 是**代码**(1/4/5/6/7/8/9),其文本映射在接口里为空(`updateFrequencyString: null`),所以"更新频率"**未核实**。
- 申请能否获批取决于提供方与主体资质,**未核实**;本报告只确认"通道存在且需要登录"。
